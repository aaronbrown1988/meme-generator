# Font Assets

This directory can contain custom fonts for meme text overlay.

## Using Custom Fonts

To use the classic Impact font for memes:
1. Download Impact.ttf (ensure you have proper licensing)
2. Place it in this directory as `Impact.ttf`
3. The application will automatically use it if present

## Fallback Font

If Impact.ttf is not found, the application uses Go Mono Bold as a fallback font.
