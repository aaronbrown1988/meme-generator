# Project Context

Domain vocabulary for the meme generator. Use these terms exactly in code,
commits, and discussion. New terms get added here when introduced.

## Domain terms

**Generation**
A single end-to-end attempt to produce a meme from a user prompt. Has a
lifecycle (`processing` → `success` | `failed`), a prompt, an image, and
optionally a caption. The unit of persistence and the unit of work for the
pipeline.

**Caption**
The top/bottom text written across a meme image in classic meme style
(white, all-caps, black outline). Either half may be empty. Conceptually
distinct from the underlying image — generated by a different model and
applied as a separate step.

**Pipeline**
The orchestration that turns a prompt into a finished `Generation`:
caption-write → image-generate → caption-render → persist. Owned by the
`meme.Generator` module. Runs asynchronously on a single worker; HTTP
handlers `Enqueue` and poll.

**Caption Writer**
The LLM-backed source of caption text. Producer of `Caption` values from a
user prompt. Failures are non-fatal — the pipeline degrades to an
un-captioned meme.

**Image Generator**
The LLM-backed source of meme images. Failures are terminal — without an
image there is no meme.

**Caption Render**
The in-process step that draws a `Caption` onto an image file. Pure
computation over pixels; no LLM, no I/O beyond the image file itself.

## Architectural shape

- `internal/meme` — domain types, ports (`ImageGenerator`,
  `CaptionWriter`, `Store`), and `Generator` (the Pipeline). Interfaces
  are defined where they are consumed.
- `internal/llm/ollama` — production adapters (image + caption) shelling
  out to the Ollama CLI.
- `internal/llm/fake` — in-memory adapters for tests.
- `internal/caption` — Caption Render module. Plain-string interface;
  no domain dependency.
- `internal/store` — SQLite-backed `Generation` repository.
- `internal/http` — HTTP handlers; thin adapter over the Pipeline.

The `meme` package is the centre of gravity. Adapter packages depend on
`meme`; `meme` depends on no other internal package except `caption`
(which itself depends on nothing internal).
